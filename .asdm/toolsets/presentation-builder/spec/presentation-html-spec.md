# Presentation HTML Template Spec

## Overview

This spec defines the structure and requirements for the HTML file generated by the Presentation Builder toolset. The generated file must be a complete, self-contained HTML document that creates an interactive demo website with fullscreen presentation capabilities.

## Key Requirements

1. **Self-contained**: All CSS and JavaScript must be inline within the HTML file. No external dependencies.
2. **Fullscreen Presentation**: Support entering fullscreen mode via a Play button on the landing page.
3. **Keyboard Navigation**: Left/Right arrow keys for slide navigation, Escape to exit.
4. **Modern Design**: Clean, professional visual design with smooth transitions.
5. **Responsive**: Works on different screen sizes.

## HTML Structure

The generated HTML file must follow this structure:

```html
<!DOCTYPE html>
<html lang="<detected-language>">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title><Presentation Title></title>
  <style>
    /* All CSS inline here */
  </style>
</head>
<body>
  <!-- Landing Page -->
  <div id="landing">
    <h1><Presentation Title></h1>
    <p><Slide Count> slides</p>
    <button id="play-btn">▶ Play</button>
  </div>

  <!-- Presentation Mode -->
  <div id="presentation" class="hidden">
    <div id="slide-container">
      <!-- Slides rendered here -->
    </div>
    <div id="nav-bar">
      <button id="prev-btn">←</button>
      <div id="progress">
        <div id="progress-bar"></div>
      </div>
      <span id="slide-counter">1 / N</span>
      <button id="next-btn">→</button>
      <button id="exit-btn">✕</button>
    </div>
  </div>

  <script>
    /* All JavaScript inline here */
  </script>
</body>
</html>
```

## CSS Design Specification

### Color Scheme
- **Background**: `#0f0f1a` (deep dark blue)
- **Surface**: `#1a1a2e` (dark surface)
- **Primary Accent**: `#4f46e5` (indigo)
- **Secondary Accent**: `#7c3aed` (purple)
- **Text Primary**: `#f1f5f9` (light gray)
- **Text Secondary**: `#94a3b8` (medium gray)
- **Code Background**: `#1e1e2e` (code block bg)
- **Success**: `#22c55e` (green)

### Typography
- **Headings**: System font stack with bold weights
- **Body**: System font stack with regular weights
- **Code**: `'Fira Code', 'Cascadia Code', 'JetBrains Mono', monospace`
- **Base font size**: 16px with responsive scaling

### Layout
- Landing page: Centered content, max-width 800px
- Slides: Full viewport, content centered vertically and horizontally
- Content area: max-width 900px with comfortable padding
- Navigation bar: Fixed at bottom, 60px height

### Animations
- Slide transitions: Fade effect (300ms ease)
- Button hover: Scale and color transitions
- Fullscreen entry: Smooth fade-in
- Progress bar: Width transition on slide change

## JavaScript Requirements

### Core Functions
1. **Slide Navigation**: `goToSlide(index)`, `nextSlide()`, `prevSlide()`
2. **Fullscreen Toggle**: `enterPresentation()`, `exitPresentation()`
3. **Keyboard Handler**: Listen for ArrowLeft, ArrowRight, Space, Escape, Home, End
4. **Progress Update**: Update progress bar and counter on slide change
5. **Fullscreen API**: Use `document.documentElement.requestFullscreen()` for browser fullscreen

### Slide Data Structure
```javascript
const slides = [
  {
    title: "Slide Title",
    content: "<p>HTML content for this slide</p>"
  },
  // ...
];
```

### Event Handling
- Keyboard events for navigation
- Click events for buttons (Play, Prev, Next, Exit)
- Touch/swipe support for mobile devices (optional but recommended)
- Window resize handler for responsive layout

## Markdown to HTML Conversion Rules

| Markdown Element | HTML Output |
|-----------------|-------------|
| `## Heading 2` | `<h2 class="slide-section">Heading 2</h2>` |
| `### Heading 3` | `<h3 class="slide-subsection">Heading 3</h3>` |
| `**bold**` | `<strong>bold</strong>` |
| `*italic*` | `<em>italic</em>` |
| `` `code` `` | `<code>code</code>` |
| ` ```lang ... ``` ` | `<pre><code class="lang">...</code></pre>` |
| `- item` | `<ul><li>item</li></ul>` |
| `1. item` | `<ol><li>item</li></ol>` |
| `[text](url)` | `<a href="url">text</a>` |
| `![alt](url)` | `<img src="url" alt="alt">` |
| `| table |` | `<table>...</table>` |
| `> quote` | `<blockquote>quote</blockquote>` |
| `---` | `<hr>` |

## Accessibility Requirements

- All interactive elements must be keyboard-accessible
- ARIA labels on navigation buttons
- Focus management when entering/exiting fullscreen
- Screen reader announcements for slide changes (aria-live region)
